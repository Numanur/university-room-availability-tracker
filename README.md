# CSE Room Availability — Fall 2026

React + TypeScript + Tailwind CSS web app for checking room availability.

## Features

- Monday to Thursday
- Six time slots per day
- 5 room cards per row on mobile
- 15 room cards per row on desktop
- Green cards indicate free rooms
- Red cards indicate occupied rooms
- Occupied rooms show room name, faculty acronym, and batch
- Clicking an occupied room opens a details modal with:
  - Room
  - Day
  - Time
  - Course name
  - Course code
  - Faculty name
  - Faculty acronym
  - Batch
- Clear button resets the selected time slot and returns the day to Monday

## Tech Stack

- React
- TypeScript
- Tailwind CSS
- Vite

## Run Locally

```bash
npm install
npm run dev
```
